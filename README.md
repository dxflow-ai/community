# dxflow

The public home of dxflow — install it, get releases, and report issues here.

dxflow is a unified platform for running and managing scientific-computing workflows.

## Install

```bash
wget -qO- https://raw.githubusercontent.com/dxflow-ai/community/main/install.sh | sudo bash
```

## Releases

Prebuilt binaries for Linux, macOS, and Windows are published under [Releases](https://github.com/dxflow-ai/community/releases).

## Issues

Report a bug or request a feature in this repository's [issue tracker](https://github.com/dxflow-ai/community/issues).
