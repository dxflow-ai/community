# Welcome to dxflow

Your workspace for running automation pipelines, inspecting generated files, and driving interactive engine sessions — all from one console.

## Get started

- **Workflows** — browse and run automation pipelines from the sidebar. Each run opens as a diagram with live logs.
- **Artifacts** — inspect and edit generated files and outputs. Text opens in the editor, images render inline.
- **Shells** — open an interactive engine session and work directly against a running engine.
- **Agent** — ask the agent for help. Responses render as rich markdown right in the sidekick.

## Tips

- Tabs open in two panes — a **primary** focus pane and a **secondary** pane for logs and shells.
- Use the **fullscreen** toggle on the secondary pane to expand logs while you work.
- Press `Cmd`/`Ctrl` + `S` to save while editing an artifact.
- Collapse the sidebar any time to give your active tab more room.
